# 0002 - No payloads in the repository

Status: accepted

## Context
The repository documents a malicious-behaviour extension.

## Decision
Publish analysis, detections and indicators only. No extension code, no payloads, no offensive use
(see "Out of scope" in [SPEC.md](../../SPEC.md)).

## Consequences
The proof-of-concept page is limited to a harmless status request, and its presence in the public
repository is an open decision in [ROADMAP.md](../../ROADMAP.md).
