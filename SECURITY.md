# Security policy

## Scope

This repository contains documentation and detection content, not running software. Relevant reports:
an incorrect indicator that could block legitimate services, a rule that is unsafe to deploy, or sensitive
data committed by mistake.

## Reporting

Use GitHub private vulnerability reporting for this repository (Security tab, "Report a vulnerability").
Do not open a public issue for sensitive data.

## Findings about the analyzed extension

Findings on CRXLauncher itself were sent through the Chrome Web Store Trust and Safety channel; see the
README. Do not send samples or exploit code to this repository.
